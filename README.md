# ఇందూ జ్ఞానవేదిక పుస్తకాలు — Android app

Features:
- 103 books and rates from the supplied PDFs
- Serial numbers
- Telugu UI
- Search
- Quantity +/- controls
- Selected-books list and grand total
- Generate PDF and share/save via Android share sheet
- Uses the supplied Telugu emblem/poster image as the only app artwork

Open this folder in Android Studio and Build > Build APK(s).
